# Customer Segmentation using KMeans Clustering

This project performs customer segmentation using KMeans clustering on a shopping dataset, focusing on features like annual income, spending score, and age.
It's affiliated with the **Prodigy Infotech Internship Program** as Task 2.


## Features

- Data preprocessing (standardization)
- KMeans clustering
- Elbow method & silhouette score analysis
- Cluster visualization using seaborn
